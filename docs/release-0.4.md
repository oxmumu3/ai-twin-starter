# 0.4.0-preview.1 发布说明

本预发布把材料整理、分身能力、消息通道和身份规则放进 DeepSeek Harness 的原生工作台，首次搭建完成后可持续管理。它用于试用和验证，尚未完成真实团队生产验收。

## 兼容与安装

- 已验证宿主：官方 DeepSeek Harness Web 0.2.1-rc.2；Node.js 22.13+。
- Desktop 0.2.1-rc.2 的集成尚未验收；其他宿主版本需重新验证。
- 阅读 README 与全部 Releases（含预发布），选择实际公开的兼容安装包，验证同一 Release 的 `SHA256SUMS`，安装后回读组件启用状态。不要仅依赖 `/releases/latest`。
- GitHub 预发布是分发渠道，不代表官方市场收录、官方审核或真实服务已上线。

## 本版新增

- 四个常驻模块：项目沉淀、分身能力、通道连接、身份与规则；首次搭建和日常管理共享状态。
- 显式选材、来源校验、模型整理与蒸馏、候选试跑及明确采用；来源变化使受影响内容需要复核。
- 根据稳定平台身份与规则，仅向执行模型提供本次获准的来源卡片，支持知识问答、草稿和授权 Slack 回传。
- 持久任务、审批、outbox、去重、游标、暂停恢复，以及发送结果未知时保留待核查状态。
- 新增本地有界 CSV 日报与材料提交/确认采用 CLI；仅由本机 Agent 显式调用，未接入原生实时服务，详见 [SETUP](../SETUP.md#本地有界工作流与材料回流)。
- 保留 0.3 通用 CLI / `agent_twin` 工具路径；其 `channel_tick` 仍强制只读 dry-run。

## 已验证

已在官方 Web 宿主的独立 profile 安装并操作原生四模块，走通项目绑定、选材、整理、蒸馏、试跑、采用、通道核验、身份规则、启用、审批、发送记录和重启恢复。该端到端路径使用明确标记的合成模型与隔离消息适配器，验证宿主 SDK、界面、权限与状态流转。

最终源码自动测试 210 项通过、0 失败、0 跳过，覆盖来源变更、到期撤权、首次多频道基线、并发锁、恢复、去重、未知发送不重试，以及新增日报和材料回流 CLI。实际安装包逐文件比对源码，排除私有运行状态、凭据、开发记录与真实业务材料。

另外通过已授权的 Harness 原生会话完成一次真实模型材料整理样本：返回合法结构、三项材料、三项缺口及正确行号，保留未授权消息通道的边界。这仅验证一次提示词样本，不替代本插件 NativeExecutor 的真实 provider 链或端到端内容质量验收。

## 仍待验收

真实模型的回答与草稿质量、真实 Slack 收发、陌生用户首次安装体验、真实同事体验、Desktop，以及长期无人值守稳定性。合成测试、安装成功、平台返回消息 ID 均不能替代这些结果；平台报告发出也不代表收件人已读。

## 使用边界

原生路径必须连接宿主真实模型和用户自己的 Slack 授权；所有者明确启用前不接单。任务执行器限于授权来源卡片的问答、草稿和消息回传，不执行任意 shell 或全宿主 Agent 工具。工具卡只是说明，真实外部工具仍需单独适配、授权和验收。宿主、电脑、模型和网络可用性共同决定在线状态。

升级前备份私有状态，保留能力历史和发送回执；按宿主流程停用旧组件并安装新版本，先用独立 profile 验收。运行步骤见 [native.md](native.md)。
