# 公开包与隐私

本项目在独立空目录重写通用机制，没有从作者的工作项目复制文件，也不继承其 Git 历史。

公开内容包括通用代码、模板、安装说明、合成测试、脱敏重写的方法示例和本项目验证记录。排除真实业务资料、人员名单、频道/消息 ID、工作区路径、聊天记录、数仓配置、业务 SQL、内部工具、原 context 正文、图片、任务状态、发送回执、凭据和设备配置。示例提炼卡的证据只指向包内合成材料，不是作者私有知识包的过滤导出。

使用者初始化后的 `.agent-twin/` 是本地工作资料，不应提交公开仓库。凭据继续留在已授权连接器的原位置；本包既不索取，也不持久化它们。不要把 ownerId 或业务路径填进仓库自带的模板，应只改自己工作区生成的文件。

蒸馏只读取用户明确选择的材料；来源元数据与卡片固定 private。读取素材及语义提炼发生在用户当前 Agent 中；使用者应沿用其已选择模型和服务的数据边界。prepare 的磁盘批次不保存全文，但其工具返回会向当前 Agent 提供所选内容。来源检测与凭据模式扫描不能证明已彻底脱敏；本项目不提供任意私有分身包的一键公开功能。

Slack token 仅从本地环境进入适配器闭包，不作为工具参数、不写项目文件、不回显错误。通道探测和dry-run回执不保存消息正文、卡片正文或token；实际身份及目的地的本地配置仍属于工作资料。

每次发布前检查源码白名单、Git 跟踪文件、完整历史和实际 tarball；源码变更后重新打包与扫描。使用全新 Git 历史不能替代包内容检查。测试和下载验收仅使用临时空目录与合成材料，不向真实渠道发测试消息。
