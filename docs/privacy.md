# 公开包与隐私

本项目在独立空目录重写通用机制，没有从作者的工作项目复制文件，也不继承其 Git 历史。

公开内容只有初始化代码、模板、安装说明、合成测试和本项目验证记录。排除真实业务资料、人员名单、频道/消息 ID、工作区路径、聊天记录、数仓配置、SQL、内部工具、context 正文、图片、任务状态、发送回执、凭据和设备配置。

使用者初始化后的 `.agent-twin/` 是本地工作资料，不应提交公开仓库。凭据继续留在已授权连接器的原位置；本包既不索取，也不持久化它们。不要把 ownerId 或业务路径填进仓库自带的模板，应只改自己工作区生成的文件。

每次发布前检查源码白名单、Git 跟踪文件、完整历史和实际 tarball；源码变更后重新打包与扫描。使用全新 Git 历史不能替代包内容检查。测试和下载验收仅使用临时空目录与合成材料，不向真实渠道发测试消息。
