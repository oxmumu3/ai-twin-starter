# 0.3.0 验证范围

日期：2026-10-19。四步为准备分身材料、蒸馏分身、连接通道、设定权限。

## 本版实际验证

完整串行测试 **116/116** 通过：材料21、蒸馏20、通道27、DSH适配25、工作区16、既有CLI流程2、新材料CLI2、零散示例1、示例工具2。命令仍为下文的完整测试命令。

当前 Agent 在全新本地目录实际读取零散的合成说明、旧报告、工具契约和不完整交接包，先保存7项材料/2个缺口；再读取带明确虚构标记的补充回答，更新为9项材料/1个保留缺口。实际读回项目说明、分类清单与缺口，三个工具状态分别为已有、待连接、待开发；不把尚未转换的旧PDF编成已知内容。

随后从材料包选定的4份原始来源生成新蒸馏批次，由当前 Agent 提炼并实际落地、读回 knowledge/judgment/workflow/tool 四类各一张卡。单独运行本地只读示例工具得到 counted=20、reserved=3、usable=17；材料准备本身没有执行工具。修改一个来源后材料桥接拒绝，受影响卡被排除；恢复原内容后再次校验。全部示例均从头编写，不是用户真实项目或真实用户回答。

独立审读发现并关闭了一个敏感路径规则不一致问题：盘点与读取现在都拒绝带空格的私人聊天目录名，错误不回显正文或合成凭据。含空格和 `~` 的示例CLI路径也有实际复制执行回归。审读通过不能替代真实业务账号验收。

源码范围检查未发现真实业务标识、个人绝对路径或真实凭据；测试中的6个凭据形状字符串均为明确命名的合成拒绝用例，测试不进入npm发布包。实际tarball、匿名下载、隔离DSH安装与自托管索引的验证结果记录在本版Release；不以源码清单代替实际包检查。

真实Slack探测仍因缺少本地授权与身份配置返回blocked；没有真实入站、本人收件、正式业务执行或持续调度证据。DSH组件测试使用真实SDK与合成宿主，不等于日常Desktop/model端到端。材料与知识均为私有派生视图，不是来客强隔离ACL或完整执行沙箱。

## 0.2.0 历史验证范围

日期：2026-10-19。三步为蒸馏分身、连接通道、设定权限；不能以安装或配置初始化代替功能验收。

## 已跑的验证

串行完整测试 85/85 通过：distill 20、channel 27、DSH adapter 20、workspace 16、CLI workflow 2。命令为：

```sh
node --max-old-space-size=256 --test --test-concurrency=1 --test-reporter=spec test/*.test.mjs
```

蒸馏测试真正读取选定文本、由带来源提案生成四类内容卡、核对版本/行号/hash，并覆盖源变化/删除、增量保留、candidate排除、手改检测、凭据不回显、范围/symlink及隐藏入口白名单。来源引用的存在和未变可以由代码验证，语义是否充分仍需当前 Agent 与本人判断。

主线程另外读取包内四份独立脱敏的合成工作方法，由当前 Agent 提炼四张非原文拼接的卡，实际执行 prepare→apply→knowledge_read，读回四类各一张。这个演示不是作者整个项目知识或能力已被复制的证明。

通道测试使用可观测的 fake fetch，真实走 Slack 只读适配器和权限代码，验证认证、owner/DM/租户、范围、账号和配置变化、限流、取消、重复请求和知识失效。发送与业务执行始终零调用，生产状态/游标不变；缺凭据的实际 CLI 探测返回 blocked。

DSH 测试使用真实 tools SDK 0.2.1-rc.2、合成宿主上下文和上述模块，覆盖 11 个操作、宿主目录、只读策略、越界、参数防秘密输入，以及实际知识消费与权限 dry-run。

源码与实际发布包的内容、隐私和安装验证记录补在对应 Release。市场索引须由官方 parser 单独验证，并使用实际固定 Git commit，不用动态分支或空白 hash 冒充可安装版本。

## 未验收的部分

没有连接真实 Slack 账号，没有验证真实入站、本人收件、正式业务执行或持续调度；也没有在日常 Desktop profile 调用模型进行完整配置。fake fetch、SDK适配和文件产物不能替代这些证据。

私有知识读取是当前 Agent 的内部上下文入口，不是按来客身份强隔离的知识库。dry-run 权限路由不构成完整执行沙箱；正式工具访问仍靠宿主授权。源码模式扫描也不能保证任何用户输入已彻底脱敏。

0.1.0 的 30 项测试、19 文件包、匿名哈希和隔离安装结果仅证明配置初始化与包管理路径。它没有实现内容蒸馏或通道探测，不能作为完整分身搭建能力的证据。该范围已在旧 Release 说明中更正。
