# 从实际工作方式到分身知识包

材料取材于作者的真实工作方法，经过独立脱敏重写。项目、实体、路径和输入全部为合成，不代表任何组织的事实、正式定义或实际数据。没有复制业务资料、原上下文、SQL、人员、频道或凭据。

sources 有四份内容：多源权威边界、先对平再判断、数据请求流程、只读工具契约。用自己的 Agent 读取它们，提炼知识、判断、工作流和工具卡，再由 distill-apply 校验来源并落包。

在临时空项目复制四份合成来源并 init，运行 distill-prepare。提炼语义的是当前 Agent，不是文件复制程序。每张卡写“何时适用、内容、限制、来源”，不要把四份原文整段拼接称为蒸馏。真实项目则选择自己的已授权来源，结果只保留本地。

示例应产出：什么可以当正式事实、何时停下判断、接请求怎样做、工具能做及不能做什么。只保存 source 路径无法提供这些能力。
