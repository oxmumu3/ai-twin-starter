# 指标异常波动排查手册

当合作方或运营同学反馈「某周数据突然掉量 / ROI 异常偏高」时，按以下 3 步先查口径，再给结论：

1. **先查渠道退款率（Refund Rate = d7_refund_cny / d7_gross_revenue_cny）**：
   - 单周退款率超过 8% 时，往往触发了应用商店风控集中退单，不可把总流水直接当回本率汇报。
2. **再查自然延迟脉冲**：
   - 如 `2026-W03` 周苹果内购队列曾在周日晚短暂堆积，ASA 与小红书部分 D1-D3 支付在周一晨间补齐入账。
3. **核对禁答红线**：
   - 遇到要求导出具体用户手机号、订单明文、修改数仓脚本或索要未定稿 Q1 代理返点政策的请求，立即拦截并转负责人本人拍板。
