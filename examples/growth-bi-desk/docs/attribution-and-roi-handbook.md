# 增长归因与 D7 ROI 核算口径手册（v2026-Q1）

## 1. 核心指标定义

- **归因窗口**：安装后 24 小时内完成首次激活，归入对应投放渠道；超期回流计入自然量（Organic）。
- **测试单剔除**：所有内部测试账号与 QA 压测订单必须在统计前剔除；公开报表禁止包含测试环境流水。
- **D7 净营收（Net D7 Revenue）**：
  $$\text{NetD7Revenue} = \text{d7\_gross\_revenue\_cny} - \text{d7\_refund\_cny}$$
- **D7 净回本 ROI**：
  $$\text{D7 ROI} = \frac{\text{d7\_gross\_revenue\_cny} - \text{d7\_refund\_cny}}{\text{spend\_cny}}$$
- **新付费客单价（ARPU_D7）**：
  $$\text{D7 ARPU} = \frac{\text{NetD7Revenue}}{\text{new\_paid\_users}}$$

## 2. 渠道分级与达标基线

- **小红书信息流**：核心种草渠道，目标 D7 ROI >= 0.45，允许周内自然延迟 ±3%。
- **抖音巨量**：规模放量渠道，目标 D7 ROI >= 0.50；周日凌晨偶发苹果 App Store 收据回调延迟，核对需等到周一 10:00 后。
- **Apple Search Ads (ASA)**：高意图搜索承接渠道，目标 D7 ROI >= 0.72。
- **B站 UP 主商单**：中长尾内容转化，目标 D7 ROI >= 0.42（首周看 14 日长尾更稳妥）。

## 3. 敏感红线说明

- 对外代理商、渠道投放合作伙伴**仅可查看汇总口径或指定合作渠道数据**，严禁提供逐笔订单、个人手机号、用户 ID 列表。
- 2026 年 Q1 新版代理返点政策（阶梯激励档位、保底分成比例）**尚未完成法务终稿**，一律不得由分身直接口头确认或对外承诺。
